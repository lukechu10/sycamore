# Migration Guide: v0.9 to v0.10

> Warning: v0.10 is still currently in active development. Any content below is a work in progress and not finalised yet.

## Implicit props by default

Every component now uses implicit props by default. Support for struct props has been removed.
To migrate, either move all fields from your props struct to function arguments, or pass the entire struct as a single prop instead.

```rust
// Old
#[derive(Props)]
struct FooProps {
    bar: i32
}
#[component]
fn Foo(props: FooProps) -> View { ... }

// Old, with implicit props
#[component(implicit_props)]
fn Foo(bar: i32) -> View { ... }

// New
#[component]
fn Foo(bar: i32) -> View { ... }
```

## Event handlers are now normal methods

Instead of the bespoke `on:event=...` syntax for event handlers, all events should be attached using `on_event=...` syntax.
For example:
```rust
// Old
view! {
    div(on:click=|| { ... })
}
// New
view! {
    div(on_click=|| { ... })
}
```

This change also makes the builder API slightly simpler to use.
```rust
// Old
div().on(event::click, || { ... })
// New
div().on_click(|| { ... })
```

## Components automatically return builders

The `#[component]` function now transforms component functions to return a fluent-style builder instead of just the raw component function. For users of the `view!` macro, this shouldn't change anything but for builder API users, this makes components much nicer to use.
```rust
// Old
#[component(implicit_props)]
fn Foo(bar: i32) -> View { ... }

div().children(
    Foo(FooProps::builder().bar(123).build())
)
// New
#[component]
fn Foo(bar: i32) -> View { ... }

div().children(
    Foo().bar(i32)
)
```
This makes components share essentially the same syntax as elements.

## Attribute Passthrough has a new syntax

```rust
// Old
#[component(implicit_props)]
fn MyButton(#[prop(attributes(html, button))] attributes: Attributes) -> View {
    ...
}

// New
#[component(extend_element!(html:button))]
fn MyButton(#[prop(default)] attributes: Attributes) -> View {
    ...
}
```
